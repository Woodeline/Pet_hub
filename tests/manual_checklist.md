## 7. 性能实测（FR-31 ~ FR-35）

| # | 操作步骤 | 期望结果 | FR |
| --- | --- | --- | --- |
| 7.1 | 启动后静置 1 分钟，任务管理器看内存 | **常驻内存 < 120MB**（自动化实测 offscreen ~42.5MB，见下） | FR-31 |
| 7.2 | 空闲状态看 CPU | **空闲 CPU < 2%**（单核） | FR-32 |
| 7.3 | 高频敲击动画期间看 CPU | **活跃 CPU < 10%** | FR-33 |
| 7.4 | 目视/录屏动画流畅度 | 活跃稳定 **30 FPS**；无输入降至 15 FPS；睡觉 8 FPS | FR-34 |
| 7.5 | 长时间空闲观察 | 减少重绘（脏区局部刷新），CPU 进一步下降 | FR-35 |

> 自动化已实测（`tests/test_memory_budget.py`）：Windows 上 `psapi.GetProcessMemoryInfo`
> 读取到完整装配 + 60 帧后 Working Set ≈ **42.5 MB**（offscreen 平台）。
> 真实桌面平台（`windows` 平台插件 + 系统托盘 + 字体引擎）内存会更高，
> **需在真实桌面用任务管理器复核**，本表 7.1 为准。
