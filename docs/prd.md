### 原始需求复述

开发一个参考同类桌宠产品的 Windows 桌面宠物程序，核心诉求是**陪伴感与情绪价值**。当检测到用户敲击键盘时，宠物同步做出"敲键盘"的动画动作以陪伴工作；宠物具备丰富的表情与动作反馈，在用户专注、休息或空闲时给出不同情绪反应；支持常驻桌面、置顶显示、鼠标拖动摆放位置，并可最小化到系统托盘。整体风格可爱治愈，运行轻量、不占用过多系统资源。

## 1. 产品目标

**一句话定位**：一只常驻 Windows 桌面、会"陪你敲键盘"的治愈系程序化猫咪，用即时动作与情绪反馈提供低成本、无打扰的陪伴感。

**3 条核心价值**

1. **即时陪伴感**：键盘敲击与宠物动作实时联动（延迟 < 100ms），让用户"看得见"被陪伴。
2. **情绪价值**：通过多档情绪状态机与 8+ 种表情，在专注/空闲/休息时给出差异化反馈，形成"被理解"的正反馈。
3. **零负担轻陪伴**：无边框、透明、可任意摆放、可收纳托盘，且性能占用极低（内存 < 120MB、空闲 CPU < 2%），不干扰工作也不拖慢系统。

## 3. 需求池

> 优先级：P0 = 必须实现（MVP 核心）；P1 = 应当实现（体验提升）；P2 = 可选（锦上添花）。
> 范围声明：本 PRD 只定义"做什么"与"验收标准"，不描述代码实现细节。

### 3.1 键盘联动（核心）

| 编号 | 需求描述 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-01 | 全局键盘敲击检测（应用失焦时仍生效） | P0 | 在任意前台窗口下敲键，程序均能捕获到按键事件；监听线程异常时不崩溃并可在日志留痕 |
| FR-02 | 敲键时宠物同步做"敲键盘"动画（双爪交替按压 + 身体微颤） | P0 | 每次按键触发一次爪子按压动画；动画自按键事件到首帧渲染延迟 < 100ms |
| FR-03 | 高频敲击判定 | P0 | 连续 300ms 内检测到 >= 3 次按键即判定为"高频敲击"，宠物进入高频敲击反馈（敲击频率更密集、身体起伏更明显） |
| FR-04 | 敲击动画与表情联动 | P1 | 高频敲击期间宠物表情切换为"专注/兴奋"，30 FPS 下动画无卡顿丢帧 |

### 3.2 情绪状态机

| 编号 | 需求描述 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-05 | 多档情绪状态机，至少含 空闲 / 专注 / 休息(摸鱼) / 睡觉 四态 | P0 | 四态可自动切换，切换逻辑符合第 5 章状态表；状态变更日志可查 |
| FR-06 | 空闲（中间态） | P0 | 无输入持续 20s~120s 期间处于"空闲"状态，视觉为轻度眨眼/左右张望 |
| FR-07 | 专注态 | P0 | 满足高频敲击条件后进入"专注"，持续敲击期间保持；停止敲击后 20s 无输入回落至空闲 |
| FR-08 | 休息/摸鱼态 | P0 | 无输入持续 >= 120s 进入"休息"（打呵欠、犯困、偶尔低头） |
| FR-09 | 睡觉态 | P0 | 无输入持续 >= 300s 进入"睡觉"（闭眼、呼吸起伏、ZZZ 气泡）；任意按键或点击立即唤醒 |
| FR-10 | 敲键即时反馈优先级最高 | P0 | 任意状态下敲键均立即打断当前表情并给出敲击反馈，反馈结束后回到原状态 |

### 3.3 表情与动作

| 编号 | 需求描述 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-11 | 至少 8 种表情，部件可独立驱动 | P0 | 实现：开心、专注、犯困、惊讶、被打扰的委屈、打呵欠、睡觉、兴奋，共 8 种；耳朵/尾巴/眼睛/腮红/嘴型可独立变化 |
| FR-12 | 表情触发条件明确 | P0 | 每种表情有明确触发条件（见下表 3.3.1），触发后 100ms 内可见变化 |
| FR-13 | 尾巴/耳朵待机微动 | P1 | 空闲状态下尾巴摆动周期 2~4s、耳朵偶发抖动，动作自然无机械感 |
| FR-14 | 眨眼与呼吸等生命体征 | P0 | 常态下每 3~6s 随机眨眼一次；呼吸起伏周期约 3s，幅度柔和 |

#### 3.3.1 表情触发条件表

| 表情 | 触发条件 |
| --- | --- |
| 开心 | 鼠标点击宠物 / 悬停抚摸 1s 以上 |
| 专注 | 进入专注态（高频敲击持续） |
| 兴奋 | 专注态下连续高频敲击累计 >= 5s |
| 犯困 | 进入休息态持续 >= 30s |
| 惊讶 | 长时间空闲（>120s）后突然收到单次敲键 |
| 被打扰的委屈 | 睡觉态中被唤醒（敲键或点击）后 3s 内 |
| 打呵欠 | 休息态随机出现，间隔 15~30s |
| 睡觉 | 无输入持续 >= 300s |

## 4. UI 设计稿描述

### 4.1 视觉构成（文字 + ASCII 草图）

**默认窗口尺寸建议**：160 × 180 px（100% 档），宠物本体占约 140 × 160 px，气泡为窗口上方临时浮层。缩放档：80% = 128×144，120% = 192×216。

```
        ┌──────────── 气泡浮层(临时, 自动淡出) ───────────┐
        │   ( 你今天敲得好多呀~ ˘▽˘ )                    │
        └───────────────────────▲────────────────────────┘
                    (指向宠物头顶的小三角尖)

   ┌──────────────────────────────────────────────┐
   │                    ▲  ▲   ← 耳朵(独立可驱动)   │
   │                  ╱    ╲                        │
   │                 (  ●  ●  )  ← 眼睛(可闭/睁/眯)  │
   │              ∩  \   ‿   /  ∩  ← 嘴型 + 腮红     │
   │                 (   ^   )     ← 脸 / 身体       │
   │                ╱  ╱ ╲  ╲                       │
   │        爪子→   ▟▙   ▟▙   ← 前爪(按压动画关键帧)   │
   │                  ╲___╱                          │
   │              (  尾巴 )→ 尾巴(可摆动)            │
   └──────────────────────────────────────────────┘
        透明背景：除猫本体轮廓外全部镂空(alpha=0)
```

**视觉层次（由下到上）**：透明底板 → 尾巴 → 身体/后腿 → 头部/耳朵 → 前爪 → 面部（眼睛/嘴/腮红）→ 气泡浮层。

### 4.3 气泡对话样式

- 形状：圆角矩形（圆角半径 8px），带指向宠物头顶的小三角尖。
- 内边距：水平 10px、垂直 6px；最大宽度 200px，超长自动换行。
- 字体：系统无衬线（如微软雅黑），字号 12px，居中。
- 出现/消失：出现 0.2s 淡入，停留 2~4s，0.3s 淡出。
- 位置：默认宠物头顶上方居中，若贴近屏幕顶部则自动翻转到下方。
- 相邻气泡间隔 >= 3s，避免刷屏。

### 4.4 托盘图标样式

- 图案：宠物猫脸简笔剪影（圆脸 + 双耳 + 两点眼 + 小嘴），透明背景。
- 尺寸：16px / 32px 两套，随 DPI 自动选择。
- 配色：主体 `#F2C79A`，描边 `#8B6B4F`，保持与窗口一致。

## 5. 情绪状态机定义

| 状态 | 进入条件 | 停留时长 | 退出条件 | 视觉表现 | 推荐台词 / 气泡文案 |
| --- | --- | --- | --- | --- | --- |
| 空闲 Idle | 无输入 20s 起（默认起始态） | 20s ~ 120s | 收到任意敲键 → 敲击反馈；无输入累计 >= 120s → 休息 | 轻眨眼、偶尔左右张望、尾巴缓慢摆动 | "需要我陪着你吗？"、"我在呢~" |
| 专注 Focus | 连续 300ms 内 >= 3 次按键（高频敲击） | 保持至停止敲击后 20s | 20s 无输入 → 空闲；>= 120s 无输入 → 休息 | 睁大眼、双爪高频按压、身体随节奏起伏 | "一起加油！💪"、"你敲得真快！" |
| 休息 Rest | 无输入持续 >= 120s | 120s ~ 300s | 任意敲键/点击 → 唤醒→敲击反馈；无输入累计 >= 300s → 睡觉 | 打呵欠、犯困、偶尔低头、眼睛半闭 | "歇一会儿吧~"、"要不要喝口水？" |
| 睡觉 Sleep | 无输入持续 >= 300s | 保持至被唤醒 | 任意敲键或点击 → 唤醒（先"委屈"表情 3s）→ 回到空闲 | 闭眼、呼吸起伏、头顶 ZZZ、淡蓝光晕 | "Zzz…"、"嘘，我在做梦呢~" |

**补充规则**

- **优先级**：敲击反馈（FR-10）> 交互反馈（点击/悬停/拖拽，FR-27~29）> 情绪状态机常态表现。
- **计时器重置**：任意一次有效敲键都会重置"无输入计时器"。
- **睡眠唤醒惩罚**：睡觉态被唤醒后 3s 内显示"被打扰的委屈"表情，之后正常回落空闲。
- **状态抖动保护**：状态切换设置最小驻留时间（>= 5s），避免在阈值附近频繁跳变。
