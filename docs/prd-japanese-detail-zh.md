# PRD：日语学习·单词详情页中文改造（增量）
> ⚠️ 历史归档：本文提到的 Jisho 链路已于 2026-09-18 随代码瘦身移除（生产侧零引用）。正文保留为历史设计记录，不再随代码同步。

- **文档版本**：v1.0（增量）
- **项目**：desktop-pet（Python 3.13 + PySide6 6.9.3）
- **Language**：中文
- **改造对象**：B 版详情窗口 `src/desktop_pet/ui/word_detail_window.py`
- **入口**：学习记录窗口 `ui/log_window.py`、生词本 `ui/vocab_window.py`（双击行 → 信号 `word_double_clicked(id)` → controller 用 `WordBank.entry_by_id(id)` 还原 `VocabEntry` → 打开**单例**详情窗口）
- **原始需求复述**：详情页**直接展示中文内容，无需英文翻译**。每个词条包含 **中文释义、词性标注、常见搭配、典型例句、语境/语气注意事项**五类内容；生词本与学习记录两个入口的**内容与展示形式保持一致**。**优先本地词库，若本地不存在可用词库则联网获取。**

---

## 1. 产品目标

**一句话**：把详情页从"中英混合"改为**纯中文一站式词条卡**（释义/词性/搭配/例句/语气五要素），采用"本地优先 + 联网兜底"策略，两入口完全一致、离线可用。

次级目标：
- 消除对 Jisho 英文数据的展示依赖，降低理解门槛。
- 本地词库可离线自给，联网路径零新增第三方依赖。
- 不触碰既有三态记忆闭环、每日配额、跨日重置、配置项。

## 4. 关键业务规则

1. **五类字段定义与展示口径**
   - **中文释义**（`translation`/`meaning` 增强）：以一句话中文解释词义，可含多义项（分条）。
   - **词性标注**：中文词性（如 名词/动词·一段/い形容词/な形容词/副词 等），可多枚标签。
   - **常见搭配**：中文描述的固定搭配/惯用组合，列表形式（每条含搭配 + 简短中文说明）。
   - **典型例句**：日文原句 + 中文翻译，列表形式；优先 1–3 条。
   - **语境/语气注意事项**：中文说明使用场景、礼貌度、褒贬、易错点等。
   - 统一约定：五类字段**均为可空数组/字符串**，缺失时该分组隐藏或显示"暂无"，不留空白框。

2. **本地优先与兜底判定**
   - 判定顺序：查 `jlpt_word_details.json` → **命中且有有效内容** ⇒ 本地渲染（不联网）。
   - 本地"缺失"定义：键不存在 **或** 五类字段全为空。
   - 本地"不可用"定义：文件不存在 / 解析失败 / 结构非法 ⇒ 视为该词未命中，转联网兜底。

3. **降级链**：`本地命中` → （未命中/不可用）`联网获取` → （无网/无 Key/请求失败）`友好提示 + 重试`。**任一环节都不得回退到英文 Jisho 内容**。

4. **两入口一致性**：两入口仅传入词条 `id`，详情窗口内部逻辑与渲染完全共用；不得因入口不同而改变字段或版式。

5. **缓存策略**：联网成功结果**写回** `jlpt_word_details.json`（增量合并写入，保留已有键）；后续打开同词直接本地命中。写入失败不影响本次展示（仅告警）。

6. **无网络/无密钥表现**：本地未命中且无法联网时，详情窗口展示已可用的基础信息（`word/kana/level`）+ 中文提示"未配置密钥，联网后可获取"（界面文案零英文残留），并提供"重试"按钮。

7. **短语/多词条处理**：以**词条 `id`** 为唯一键（非词面文本），避免一词多义或多词条同形冲突；短语类词条按同一五要素结构展示，搭配/例句数量可放宽。

8. **不改动既有闭环**：三态记忆（记住了/生词本/未处理）、每日配额、跨日重置、B 版显示时长与每日数量配置**均保持原样**，本次仅改详情窗口数据源与展示。

## 5. 详情页字段与展示草案

### 5.1 字段表

| 区块 | 字段 | 来源（本地 JSON 键） | 类型 | 必填 | 展示 |
|------|------|----------------------|------|------|------|
| 头部 | 词条（word） | `jlpt_words.json.word` | str | 是 | 大字号标题 |
| 头部 | 假名（kana） | `.kana` | str | 是 | 标题下方 |
| 头部 | 等级（level） | `.level` | str | 是 | 标签徽章（N5–N1） |
| 头部 | 来源标注 | 运行时（`_source_label`） | 枚举 | 是 | 假名下独立文字行；"来源：本地词库 / 用户缓存 / 联网获取"；纯文字、样式不因来源改变 |
| 分组1 | 中文释义 | `details.meaning_zh` | str/str[] | 否 | 正文，多义项分条 |
| 分组2 | 词性标注 | `details.pos_zh` | str[] | 否 | 标签组 |
| 分组3 | 常见搭配 | `details.collocations` | obj[]（搭配+说明） | 否 | 列表 |
| 分组4 | 典型例句 | `details.examples` | obj[]（日文+中文） | 否 | 列表，日文加粗/中文次行 |
| 分组5 | 语境/语气 | `details.usage_note_zh` | str | 否 | 段落/提示框 |
| 状态区 | 状态 | 运行时（`_status_label`） | 枚举 | 是 | 加载中 / 失败+重试；成功时隐藏（来源由头部标注） |

### 5.2 版面结构（自上而下）

```
┌──────────────────────────────────────────────┐
│ [词条 word]                    [N4]  ← 头部   │
│ 假名 kana                                     │
│ 来源：本地词库           ← 来源标注（假名下）  │
├──────────────────────────────────────────────┤
│ 中文释义                                      │
│  · 释义一                                      │
│  · 释义二                                      │
├──────────────────────────────────────────────┤
│ 词性  [名词] [一段动词]                        │
├──────────────────────────────────────────────┤
│ 常见搭配                                      │
│  · 搭配A —— 中文说明                           │
│  · 搭配B —— 中文说明                           │
├──────────────────────────────────────────────┤
│ 典型例句                                      │
│  1. 日文原句                                   │
│     中文翻译                                   │
│  2. …                                         │
├──────────────────────────────────────────────┤
│ 语境 / 语气                                   │
│  …注意事项（提示框样式）…                      │
├──────────────────────────────────────────────┤
│ 状态：加载中 / 失败提示            [重试]      │
└──────────────────────────────────────────────┘
```

- **状态区**三态：加载中显示占位/进度、失败显示友好提示 + "重试"；**成功时状态区隐藏**，来源由头部（假名下 `_source_label` 独立文字行）标注。
- **来源标注**为纯文字，内容样式统一、**不因来源（本地词库 / 用户缓存 / 联网获取）不同而改变样式**——仅作排查与信任提示。
- **两入口**渲染同一窗口实例与同一套布局，仅数据随 `id` 变化。
- **本地命中**时应**同步即时**呈现（无加载态闪烁）。
